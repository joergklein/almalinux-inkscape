# Inkscape for AlmaLinux 10

This project provides native RPM packages of [Inkscape](https://inkscape.org/) for AlmaLinux 10 on x86_64.

## Features

- Native RPM package for AlmaLinux 10
- Latest stable Inkscape release
- Automatic dependency resolution through DNF
- Installation and updates using the RPM package manager

## Supported platform

| Distribution | Version | Architecture |
|---|---|---|
| AlmaLinux | 10 | x86_64 |

## Installation

### 1. Enable EPEL

Inkscape requires additional runtime dependencies provided by EPEL.

```bash
sudo dnf install -y epel-release
```

### 2. Download the RPM package

Download the latest RPM package:

```bash
curl -LO https://github.com/joergklein/almalinux-inkscape/releases/latest/download/inkscape-latest.x86_64.rpm
```

### 3. Install Inkscape

Run the following command in the directory containing the downloaded RPM:

```bash
sudo dnf install ./inkscape-latest.x86_64.rpm
```

DNF automatically resolves and installs the required dependencies.

## Starting Inkscape

Start Inkscape from the application menu or run:

```bash
inkscape
```

To display the installed version:

```bash
inkscape --version
```

## Version information

Inkscape displays its application version, source revision and date. For example:

```text
Inkscape 1.4.4 (dcaf3e7d9e, 2026-05-05)
```

The output contains three pieces of information:

- `1.4.4` is the Inkscape application version.
- `dcaf3e7d9e` is the short Git commit hash identifying the source revision.
- `2026-05-05` is the date associated with that source revision.

This information is generated by Inkscape itself. It is separate from the RPM package version and release number.

## Updating

Download the latest RPM package:

```bash
curl -LO https://github.com/joergklein/almalinux-inkscape/releases/latest/download/inkscape-latest.x86_64.rpm
```

Install it with:

```bash
sudo dnf install ./inkscape-latest.x86_64.rpm
```

DNF updates the installed package and handles its dependencies.

## Uninstalling

Remove Inkscape with:

```bash
sudo dnf remove inkscape
```

To remove dependencies that are no longer required by other installed packages:

```bash
sudo dnf autoremove
```

## Automated updates

GitHub Actions checks for new stable Inkscape releases automatically on the 1st day of every month at 02:00 UTC. The workflow can also be triggered manually.

If a newer stable Inkscape version is available, the workflow builds the RPM packages and publishes a new GitHub Release. The release includes versioned RPM packages and the `inkscape-latest.x86_64.rpm` download alias.

If no newer version is available, no build or release is created.
